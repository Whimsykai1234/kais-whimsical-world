   ## About the pattern

   I started using this pattern to make a giant duvet, which is probably my biggest project so far. Doing them I learned how to properly attach granny squares in order to create a big project. With the main pattern, you'll be able to creat a 12x12cm granny square using a 3.5mm hook and a 3-4mm yarn.

   This granny square has got three main parts: the flower's core, the flower's petals and the backgroound. You'll have to use 3 different yarn colors, or you can also make the core and the petals with one color, then switch to a second color for the background.

   Each granny square takes about 45-65min. 

   After round 2, we'll be using two colors. Whenever we change color, we'll crochet into the last round of that same color. For example, in round 5 we'll crochet with color 2 into the stitches created in round 3, in which we also used color 2. 

   ## Pattern

With color 1:
- Round 1: 8sc in a magic ring

- Round 2: 8dc increase (16) 

Cut and change color. Insert color 2 in any stitch from round 2.

- Round 3 (color 2): (ch3, dc inc), ch1, sk1, [3dc (same stitch), ch1, sk1] x 7

Insert color 3 free from round 2.

- Round 4 (color 3): ch7, [1dc, ch4] x 7
- Round 5 (color 2): ch3, dc inc, dc, ch2, [dc, dc inc, dc] x 7

## Tips
   I recommend using a 50% acrylic 50% cotton yarn in order to make a duvet or a cushion. If insted you're planning on making a blanket, 100% wool yarn would be better. 
   Before assembling the squared, make sure you iron them- they'll gain at least 1x1cm.
